# VP Board Better v1.1.0

## 自绘窗口（这一版最大的变化）

- 窗口、标题条、最小化 / 最大化 / 关闭都由 `VPBoardBetter.exe` 自己画（WebView2 承载页面），不再是 Edge 的 `--app` 窗口，也不会出现系统标题栏叠在页面上；
- 标题条只在加载比赛后显示比赛名，左上角是程序自己的气球图标；
- 关窗即退服务：结束 8787 上的 node，关掉 QOJ 用的后台浏览器。

## 启动更快

冷启动 3.65s → 0.8s 左右：

- 服务在后台线程并行启动，不再阻塞窗口创建；
- WebView2 立刻初始化（以前白等 2.5 秒的兜底定时器已删掉）；
- 等页面时先显示自绘的启动画面（气球 + 进度条），不是黑屏。

## 其它

- 3 小时模式改成非线性时间轴：开场接近真实速度，越往后越快，5 小时比赛正好在 3 小时整点收尾；封榜区仍按比例压缩（原 60 分钟 → 36 分钟），帮助里能看到曲线；
- QOJ 提交仍在后台浏览器里完成，登录一次就记住。

## 这一版一并清理

- 删掉早期「用 helper 去掉系统标题栏」的整套死代码（约 2200 行）、旧的 `.bat` / `.vbs` 启动链和过期脚本；
- 仓库体积 46 MB → 6.9 MB。

## 附件

`VPBoardBetter-v1.1.0.zip`（35 个文件）：解压后双击 `VPBoardBetter.exe` 即可，不需要装 Node，也不需要管理员权限。
