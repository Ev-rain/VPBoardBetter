# VP Board Better · 虚拟榜单回放

把一场 XCPC / ICPC 比赛的真实榜单数据当成录像回放：时间轴能拖、能暂停、能跳，榜单按时间点实时重算。

标准 5 小时 VP 之外，还能把整场压进 3 小时——开场几乎按真实速度出题，越往后越快，整场仍在 3 小时整点收尾。

## 两种时长

| 模式 | 时间轴 | 封榜 |
| --- | --- | --- |
| 完整时长 | 与比赛原始时长 1:1 | 与原始封榜时间一致 |
| 3 小时 | 非线性：开场接近 1:1，越往后越快，5 小时比赛正好 3 小时刷完 | 封榜区仍按比例压（原 60 分钟 → 36 分钟） |

3 小时模式下格子里仍是**原始比赛时间与罚时**，鼠标悬停能看到换算后实际出现在第几分钟、按压缩时间算的罚时。「说明」里有这条曲线，鼠标移上去可以查任意时刻。

## 怎么启动

双击 **`VPBoardBetter.exe`**。关掉窗口，本地服务会一起退出。

## 加载比赛

打开后点「数据源」：

- 点「选择榜单」，按名字 / 城市 / 路径搜 XCPCIO 的比赛列表，点一行自动填好；
- 或直接粘贴链接、路径，例如 `https://board.xcpcio.com/icpc/50th/nanjing`、`icpc/50th/nanjing`；
- 或把 `config.json`、`team.json`、`run.json` 拖进窗口。

同一行还能填这场比赛的 QOJ 链接（可以点「搜索这场比赛」按赛站名搜，或从列表里挑，或只填 `4597`）。填一次记在这一场上，换比赛换链接。

## 时间轴

| 操作 | 快捷键 |
| --- | --- |
| 播放 / 暂停 | `空格` |
| 后退 / 前进 1 分钟 | `←` / `→`（按住 `Shift` = 5 分钟） |
| 聚焦搜索框 | `/` |
| 关闭弹窗 / 抽屉 | `Esc` |

拖动进度条任意跳转，右侧「完整时长 / 3 小时」随时切换。

走到封榜时刻会出现「封榜中」徽标与倒计时，时间轴末段斜纹区就是封榜区，到终点自动揭榜。

比赛结束后，控制条右侧出现「查看题解」：用默认浏览器打开这场的 QOJ 题解，优先中文。

## 榜单

- 排名：过题数降序 → 罚时升序 → 最后过题时间升序 → 队名。
- 罚时：每题首次通过的比赛时间 + 20 分钟 × 该题此前的失败次数。编译错误（CE）不计罚时、也不占格子。
- 一血格有虚线内框；封榜期未揭晓的格子显示 `?`，悬停能看到已记录的失败次数。
- 可搜索队伍 / 学校 / 队号，可勾「只看正式队伍」「奖牌线」；点任意队伍看详情（名次、每题通过时刻、队员与教练、提交记录）。

## 我的队伍

点右上「我的队伍」：

- **创建我的队伍**：不用填信息，直接以「我 · 本机」进榜，按你记录（或 QOJ 提交）的结果实时算；
- **从已有队伍中选择**：高亮你在榜单里的那支队，再补记自己的提交。

之后点「记录提交」：选题目、AC / 失败 / 编译错误、提交时间（默认当前时刻，`分:秒`）。记录存在本机。

## QOJ 交题（可选）

设好「我的队伍」后点「提交到 QOJ」：选 A/B/C、贴代码、提交。页面显示评测状态，结束后自动按**当前榜单时间**记成一次提交。

第一次要填一次 QOJ 账号密码。用户名自动记住；密码默认不保存（登录态靠 cookie），想连密码一起记就勾「记住密码」。

## 常见问题

- **结束后没有「查看题解」**：确认「数据源」里关联的是正式赛（热身赛一般没有题解附件）；按钮出现后点一下会重新取。
- **QOJ 登录卡住**：到 Cloudflare 的验证没过去，打开「提交到 QOJ」里的「诊断日志」看卡在哪一步，再试一次。

## 数据来源与许可

榜单数据来自 [XCPCIO board](https://board.xcpcio.com) 与 [xcpcio/board-data](https://github.com/xcpcio/board-data)；示例数据是 2025 ICPC 南京站（359 队 / 4075 次提交）。
